## Run Demos Locally  

1. Clone the current repository:  

    ```cli  
    # HTTPS 
    git clone https://github.com/DevExpress/demos-mvc-5.git
    ```
    ```cli
    # SSH 
    git clone git@github.com:DevExpress/demos-mvc-5.git  
    ```

2. Open a required solution from the following folder in your IDE: [ASP.NET/CS](https://github.com/DevExpress/demos-mvc-5/tree/main/ASP.NET/CS). 
3. Run the application in a [supported browser](https://docs.devexpress.com/AspNetMvc/404393/supported-browsers).
